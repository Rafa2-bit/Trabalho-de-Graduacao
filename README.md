### <a id="primeiro-semestre-2024-2"></a>Primeiro Semestre (2024-2)

* **Empresa Parceira:** FATEC São José dos Campos — Prof. Egydio.

* **Problema:** 
Funcionários de uma empresa enfrentam dificuldades para compreender a dinâmica prática da metodologia ágil Scrum apenas por meio de materiais teóricos e aulas expositivas. A ausência de vivência simulada sobre papéis e artefatos gera insegurança no início dos projetos integradores, resultando em falhas na divisão de tarefas, dificuldade na estimativa de entregas e baixa eficiência na comunicação entre os membros das equipes recém-formadas.

* **Solução:** 
Para resolver o problema proposto, a equipe desenvolveu o **EasyScrum**, uma aplicação web educacional interativa voltada ao ensino prático da metodologia Scrum. O sistema guia o usuário por meio de trilhas de aprendizagem estruturadas, simulações de Sprints, quizzes avaliativos e exemplos aplicados de cerimônias e artefatos ágeis, permitindo que assimilem o fluxo de trabalho antes e durante a execução dos projetos.

### <a id="segundo-semestre-2025-1"></a>Segundo Semestre (2025-1)

* **Empresa Parceira:** FATEC São José dos Campos.

* **Problema:** 
Engenheiros de software necessitam de um ambiente de desenvolvimento integrado (IDE) que ofereça suporte a análise de código, geração de gráficos e visualização de dados em tempo real, especialmente para projetos que envolvem Python e bibliotecas como Matplotlib. A ausência de uma ferramenta centralizada resulta em dificuldades na depuração, inconsistências na apresentação dos resultados e aumento do tempo gasto em tarefas manuais de configuração.

* **Solução:** 
Para resolver o problema proposto, a equipe desenvolveu o **BotEcho** uma aplicação desktop que integra um ambiente de desenvolvimento com suporte a análise de código Python, geração de gráficos e visualização de dados em tempo real com IA. O sistema permite que os engenheiros escrevam, testem e depurem scripts Python, visualizem gráficos interativos e exportem resultados diretamente para relatórios, otimizando o fluxo de trabalho e reduzindo erros manuais.

### <a id="quarto-semestre-2026-1"></a>Quarto Semestre (2026-1)

* **Empresa Parceira:** Exército Brasileiro — Guarnição de Caçapava

* **Problema:** 
A Guarnição de Caçapava enfrenta desafios na gestão de obras e na elaboração de orçamentos técnicos devido à complexidade dos processos envolvidos, que incluem análise de plantas CAD, cálculo de custos unitários e totais, acompanhamento do cronograma físico-financeiro e geração de documentação técnica padronizada. O processo manual é demorado, propenso a erros e não atende às demandas operacionais da instituição.

* **Solução:** 
Para resolver o problema proposto, a equipe desenvolveu o **EchoCAD**, uma aplicação web para extrair informações de uma planta CAD e gerar automaticamente uma documentação técnica utilizando inteligência artificial. O sistema permite que os usuários façam upload de arquivos CAD, realizem a análise das plantas, calculem custos e cronogramas, e gerem relatórios técnicos padronizados, otimizando o fluxo de trabalho e reduzindo erros manuais.
